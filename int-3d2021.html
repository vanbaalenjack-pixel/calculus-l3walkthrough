Question

The diagram below shows part of the graph of the function

\[ y=\frac{3x-2}{x+2}. \]

Find the shaded area.

You must use calculus and show the results of any integration needed to solve the problem.

The diagram is shown in its initial state. JavaScript adds any interactive controls and later walkthrough visuals.

First walkthrough idea

Focus to try first

Find the \(x\)-limits from the \(y\)-values shown on the graph, then integrate the curve above the \(x\)-axis.

Step 1

Find the x-limits

The endpoints of the shaded region occur where the curve has \(y=1\) and \(y=2\).

Show the first step’s working
\[ 1=\frac{3x-2}{x+2} \Rightarrow x+2=3x-2 \Rightarrow x=2 \] \[ 2=\frac{3x-2}{x+2} \Rightarrow 2x+4=3x-2 \Rightarrow x=6 \]
