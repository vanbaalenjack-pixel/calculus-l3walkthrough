Question

The graph below shows the function \(y=f(x)\).

(i) Find the value(s) of \(x\) where \(f(x)\) is continuous but not differentiable.

(ii) Find the value(s) of \(x\) where \(f'(x)=0\).

(iii) Find \(\lim\limits_{x\to -1}f(x)\), or state clearly if it does not exist.
