Question

The graph below shows the function \(y=2\cos\left(\frac{x}{2}\right)\).

Find the value of \(k\) so that the shaded Area A will be equal to the shaded Area B.

You must use calculus and show the results of any integration needed to solve the problem.

Hint to try first

If Area A equals Area B, each one must be half of the total shaded area.
