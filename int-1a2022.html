Question

\[ \text{Find } \int \left(\frac{4}{x}-\sec^2 x\right)\,dx. \]

First walkthrough idea

Focus to try first

Split the integrand into two familiar pieces before integrating.

Step 1

Split the integrand

Each term already matches a standard antiderivative, so it is easier to integrate them separately.

Show the first step’s working
\[ \int \left(\frac{4}{x}-\sec^2 x\right)\,dx = \int \frac{4}{x}\,dx-\int \sec^2 x\,dx \]
