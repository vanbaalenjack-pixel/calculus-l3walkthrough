Question

The gradient function of a curve is

\[ \frac{dy}{dx}=\frac{8}{x^3}. \]

Find the equation of the curve if it passes through the point \((1,3)\).

First walkthrough idea

Focus to try first

Integrate the gradient function, then use the point \((1,3)\) to find \(C\).

Step 1

Rewrite the gradient

The power rule is easier to apply when the denominator is written as a negative power.

Show the first step’s working
\[ \frac{dy}{dx}=\frac{8}{x^3}=8x^{-3} \]
